# ApocaChaseCamera 0.1.6 verification

October 8, 2026. Compiled successfully against the installed Unity, NWH Vehicle Physics, PlayMaker, BepInEx, Harmony and Apocasetter assemblies. All 2,449 simulated checks passed, including the existing 2,137 checks and 312 new regression checks. The fixture set covers all 14 extracted stock vehicle camera setups.

New regressions cover live pitch edits at both vertical limits; missing post-render callbacks with normal Update and direct Apply; same-frame render idempotence; four-query clear frames; stopping at an unchanged collision candidate; retained sweep/ray/overlap growth and complete results beyond the 4,096-hit capacity limit; missing and replaced camera components and anchors; seat changes; immediate health, aiming and visibility guards; bounded binding discovery; optional-interface validation and one-warning failure handling; inventory replacement, destruction and reparenting; bounded graphics/bounds refresh; delayed font availability; unchanged gear string reuse and in-place gearing edits; static gauge artwork reuse and resizing; and owned-sprite cleanup without destroying native textures.

Ordinary camera frames use four buffered physics calls, compared with six before the fixes. The 600-frame ordinary driving simulation makes exactly 2,400 buffered queries and no allocating physics-result calls. Buffers grow only when needed, retain capacity through resets and preserve a full-query fallback when the maximum reusable capacity fills. Inventory hierarchy scans are bounded at 0.5 seconds, with immediate direct-child invalidation; graphic bounds refresh at 0.1 seconds, while four cached corners follow the inventory's current pose each frame.

The optional Apocaplayer bridge was exercised against an interface double, including incompatible types and throwing callbacks. Actual installed third-party camera behavior, native rendering matrices, PhysX geometry, GPU cost and frame times are not simulated. The fixed build requires an in-game drive test, including storms if used with the independent ApocaDustStorm mod.

Camera tuning, native transforms, vehicle physics and saved settings retain their behavior. The installation archive contains only ApocaChaseCamera/ApocaChaseCamera.dll and ApocaChaseCamera/README.md. Source and verification are in a separate developer archive; previous 0.1.4 and 0.1.5 archives are retained. The build has not been installed or published by this task.
