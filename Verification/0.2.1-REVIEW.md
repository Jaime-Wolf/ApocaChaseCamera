# ApocaChaseCamera 0.2.1 runtime fix

The user installed the exact 0.2.0 DLL and reported that Apocaplayer still controlled the camera. BepInEx/LogOutput.log confirms version 0.2.0 loaded, followed by:

`Apocaplayer bridge disabled: Operation is not supported on this platform.`

Inspection of the installed game's mscorlib.dll shows that Reflection.Emit.DynamicMethod constructors call Unity.ThrowStub.ThrowNotSupportedException. The prior tests ran on desktop .NET, where those constructors work, so they missed the runtime incompatibility.

## Change

Field accessors now build Cecil IL and explicitly use MonoMod.Utils.DMDCecilGenerator, supplied by BepInEx, instead of Reflection.Emit.DynamicMethod. Typed access and existing camera/compass/zoom/collision behavior are retained. Runtime failures include a full exception trace. No Apocaplayer, Apocasetter or installed game files were changed.
