# ApocaChaseCamera 0.2.2 - native aim recenter

The user confirmed that 0.2.1's Unity-compatible Apocaplayer bridge works, then reported that the crosshair remains aimed where the last manual look stopped while the visible camera automatically returns behind the vehicle. Left was an example; the problem applies to any direction.

## Finding and change

Apocaplayer's unchanged LateCrosshair computes its ray from the native eye's transform and then projects that point using the shared chase pose. The projection updated correctly in 0.2.1; native aim did not follow passive recenter. DrivingAim.cs synchronizes only the eye rotation and active native MouseLook input accumulators during a valid, unarmed, ChaseCamera-owned recenter. Typed instance writers explicitly use the installed MonoMod Cecil backend. Discovery is cached and bounded; only actions targeting the eye qualify. MouseY and combined-axis pitch signs, seat-local rotations, disabled settings and camera ownership are covered. No player/vehicle positions or steering target are changed.
