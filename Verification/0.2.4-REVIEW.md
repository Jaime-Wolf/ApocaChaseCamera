# ApocaChaseCamera 0.2.4 review and verification

October 9, 2026. The user confirmed the 0.2.3 crosshair auto-recenter fix in game and authorized fixes for the three full-folder audit findings, with the pre-fix ZIP preserved.

## Implemented fixes

1. DrivingAim supports the exact native PlayerCameraHolder targeted by the player's own Look actions, including the stock scene-root layout. Holder rotation and input caches follow the owned passive recenter pose using the target's parent coordinates. Player and Direction/steering targets are not written. The installed MouseLook IL was checked: MouseY inverts its incoming delta, not the stored local pitch. Synchronization and the handwritten test double now use that actual convention. The final eye correction remains authoritative after holder writes.
2. CameraBinding caches the native holder and discovers an eye already reparented to the current seat. An exact-name fallback is restricted to the player/seat hierarchy. It also handles a replaced seated eye and rejects unrelated cameras. Discovery retries remain bounded; no per-frame global camera search was added.
3. DrivingHud negatively caches a missing VehicleController for half a second. Switching vehicles resets the delay immediately; a controller added later still recovers. Numeric readings and gauge behavior are retained.

Production changes are limited to CameraBinding.cs, DrivingAim.cs, DrivingHud.cs and the 0.2.4 version in Plugin.cs. ChaseView.cs, ApocaplayerBridge.cs, CompassView.cs and the other production implementation files are byte-for-byte unchanged from the preserved 0.2.3 source. Apocaplayer and Apocasetter were not modified.

## Scope and remaining checks

This is a built and packaged local update, not an installation or publication. The user-confirmed 0.2.3 behavior has regression coverage, but 0.2.4 has not been played in Unity. Check mouse resume after recenter, camera switching, tilted vehicles, load while seated, and vehicle entry/exit using IN-GAME-CHECKLIST.md. Operation-count checks demonstrate bounded searches, not measured CPU or frame-time improvements; no runtime performance profiling was performed. The lightweight Transform double does not model every Unity hierarchy/rotation behavior, so live input transitions remain necessary.

Install ZIP contains only ApocaChaseCamera/ApocaChaseCamera.dll and ApocaChaseCamera/README.md. Source and verification are in the separate developer archive. No original game code/assets or other-mod implementations are bundled.
